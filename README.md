# FridgeLife

FridgeLife tells you exactly when leftovers expire: pick the food, enter the cook date, get fridge and freezer eat-by dates plus spoilage signs. Free.

## Features
- Eat-by date calculator: enter the cook date, get fridge and freezer deadlines
- Searchable 22-food database with fridge/freezer windows and spoilage signs
- 2-hour rule, danger-zone and 165°F reheating guidance built in
